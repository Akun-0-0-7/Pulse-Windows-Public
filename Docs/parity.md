# 与 Pulse 1.12.2 的功能对应

对照上游提交 `b035a7acf1aad9c1b6f9f895197ad1a5f58ea64e`。Windows 程序使用 WPF 桌面框架，系统托盘对应 macOS 菜单栏；凭据使用 Windows 当前用户数据保护。原应用的 macOS 专用系统接口改为 Windows 接口。

“实现”表示已有实际请求、解析或交互代码；“离线检查”使用合成文件和服务响应；“真实账号”表示实际向服务商查询过。三者分别登记，目录中的服务数量不代替账号验证。

| 功能 | Windows 对应实现与验收 |
|---|---|
| 圆环、已用/剩余、自定义颜色、多个窗口 | 已实现；主额度可自动选择或指定，第二内环排除主额度，按服务返回的窗口长度画时间弧。 |
| 悬停详情、分段/连续进度、重置时间 | 已实现；刷新更新可见值并保留输入字段和浮动详情滚动位置。 |
| 详细卡、本机最近用量、窗口 API 等值 | 已实现；今日/7 天/31 天、模型、缓存、31 天小图和已观察额度趋势。只将默认本机登录关联到本机记录，显式账号和额外账号不借用另一账号历史。API 是服务的程序接口。 |
| Codex 历史、重置积分及到期时间 | 已实现主动读取按钮；只允许使用本机登录的主账号。工具不提供的字段保持缺省。 |
| Claude/Codex 提示词缓存 | 按本机请求时间、模型和已记录缓存层级读取；Codex 的至少 30 分钟复用期与 Claude 的 5 分钟/1 小时层级分开显示。 |
| 消耗速度预测 | 已实现，默认关闭；跨重置、估算余额及不增长窗口不外推。 |
| agent 工作标记和动画机器人 | 已实现本机活动识别、旋转点及独立绘制的 18 种身体、8 种性格。agent 指执行模型任务的客户端。 |
| 托盘数字、圆环、双额度及账号总览 | 已实现 Windows 托盘形式；可以指定账号，或选择当前最接近用尽的账号。 |
| 四边停靠、自由悬浮、吸附、折叠 | 已实现；离线检查涵盖右/下边尺寸变化、自由位置、负坐标显示器和 150% 缩放几何。 |
| 多显示器、位置记忆、跟随鼠标 | 已实现按显示器记忆和物理像素移动；断开时回退可用显示器。实际多屏拖动单列在验证记录。 |
| 全屏隐藏、快捷键、截图排除、启动项 | 已接入 Windows 原生接口；快捷键冲突显示在设置页。截图排除由所用捕获工具是否遵守系统接口决定。 |
| 深色、浅色、透明主题 | 已实现；透明表面是 Windows 透明窗口效果，macOS Liquid Glass 为原平台系统视觉。 |
| 阈值、耗尽、重置、失败、低余额、故障通知 | 已实现，默认关闭；真实重置排除充值/估算回落，持久化去重，服务故障只监控启用账号对应的官方组件。 |
| 5 小时重置后发送 `hi` 并刷新额度 | 0.1.4 已实现，默认关闭；仅本机登录的 Codex/Claude Code 主账号可按账号开启。独立每秒检查服务商返回的非估算、无模型分组的 `fiveHour` 窗口，`weekly` 不单独触发；开始与结束小时相同表示全天。到点先保存认领再发送一条普通 `hi`，发送前后请求真实额度刷新；同周期重启去重、已存计划五分钟内补处理。合成回归见 `five-hour-reset.zh-CN.md`，发布和安装结果另见验证文件。 |
| 76 个服务 | 24 项手写及 52 项配置式实际适配；Windows 登录、区域/工作区发现、接口和样例覆盖见两个服务实现说明。 |
| Codex | 已在本机真实登录下通过接口和 app-server 两条额度读取；不发送推理消息。app-server 是 Codex 提供的本机进程协议。 |
| DeepSeek、Claude 及其他账号 | 已实现相应接口或登录路线；未在本次交付中逐个使用真实账号。样例和协议检查见实现说明。 |
| 同服务多账号 | 独立凭据、标签、颜色与开关；额外账号不回退本机主登录，清理包含接口/控制台/桌面三类会话。 |
| 54 项本机消耗来源 | 逐来源原生、数据库、压缩、二进制或导出解析；字段关系、重复副本、累计量和路径说明见 `spend-status-implementation.md`。 |
| 消耗图、模型明细、分页、排序 | 已实现时间范围、按日/模型/客户端、模型输入/输出/缓存及小时分布；累计记录排除小时画像，部分计数和未定价数明确显示。 |
| 模型价格、长上下文、7 种币种 | 已实现公开价格缓存、层级价格和每日汇率；换币种清除旧手动汇率，缺价格或汇率保留缺省/美元标签。 |
| 日/周/月/年报告、8 模板、历史期间、订阅比较 | 已实现保存、复制、剪贴板文件分享和上期比较；报告使用 CPU 绘制，通过空数据/有数据/366 天热力图像素检查。CPU 是中央处理器。 |
| 月度回顾通知 | 已实现，当月 1 日且上月有已读取记录时提醒，按月份去重。 |
| 44 个官方状态页 | 已实现格式解析、组件筛选、历史条带和官方可用率；打开页面及停留期间每 5 分钟读取。 |
| 扩展、指标趋势 | 已实现 schemaVersion 1，目录发现不执行；主动开启后才运行，输出/时间有上限，趋势最多两幅。schemaVersion 表示协议版本。 |
| 诊断、代理 | 来源、时间和脱敏答复保留在内存；网络、自定义/关闭代理及本机工具环境传递已接通。 |
| 缓存 JSON、回顾、Claude 状态栏 | 已实现五种命令模式；缓存 JSON 不联网，状态栏安装保存原设置并可恢复。JSON 是带字段名称的结构化文本。 |
| 账号链接与脚本接入 | 已实现 `pulse://account/账号编号`，常驻时交给运行实例；PowerShell、Windows Terminal 等可读取命令行 JSON。macOS 菜单工具和 Raycast 的安装包不作为 Windows 程序分发。 |
| 六语言 | 简体/繁体中文、英语、日语、韩语、俄语；动态文本和大数单位随语言切换。 |
| 应用更新 | Windows 更新清单和升级包流程见 `updates.md`；使用公开仓库的 Windows 更新清单，由用户在“关于与更新”中配置地址。 |

公开版的构建、检查和发布包验证记录见 `verification.md`。
