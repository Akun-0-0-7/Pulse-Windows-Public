# Codex 本机 Token 记录为空时

从 `0.1.6-preview.5` 起，Token 统计支持自定义 Codex 数据目录和 `CODEX_HOME`。

Token 统计读取本机会话日志，与 Codex 可执行文件的安装版本和路径分开。旧版只读取默认 `.codex` 中的记录；如果当前 Codex 使用另一个数据目录，Token 页面可能只读到旧日志，在默认最近七天范围内显示零条。

## 使用

1. 退出旧版 Pulse，解压并运行新版。
2. 打开“设置 → Token 消耗”，确认启用“读取本机消耗记录”，来源中包含 Codex。
3. 查看“Codex 日志目录”。自动检测优先使用 Pulse 进程的 `CODEX_HOME`；未设置时使用用户目录下的 `.codex`。
4. 如果显示的路径不对，在“Codex 数据目录”选择当前 Codex 使用的根目录，再点击“应用目录”。应选择包含 `sessions` 或 `archived_sessions` 的根目录，不要选择这些子目录本身。
5. 点击“重新扫描”，并检查页面日期范围。

显式保存的目录优先于环境变量。点“自动检测”可清除目录覆盖值，之后仍需重新扫描。路径改变后不会继续复用旧目录的空扫描结果；不需要删除缓存。

Pulse 从桌面单独启动时，其环境变量可能与终端不同。显式选择数据目录可以避免这一差异。界面会展示实际读取的会话目录和归档目录。

## 统计与安全范围

每次使用同一个数据根中的 `sessions` 与 `archived_sessions`，重复归档记录会去重。Token 可包含输入、输出和缓存读取；金额无法估价时仍保留已读取的 Token 计数。本机记录和订阅额度是不同指标。

本次修改不调整 Codex 可执行文件、登录、模型、代理和 hi 自动发送设置，也不修改原始会话日志。价格与汇率更新仍沿用原有扫描行为。软件不会自动搜索其他用户目录或合并多个 Codex 数据根。

回归测试使用临时目录与虚构 JSONL，覆盖优先级、默认目录、归档去重、空缓存换根、异常路径、目录保存和实际读取路径显示。真实日志诊断只在本机内存中解析并输出汇总；真实路径、日志内容与统计不进入发布包或公开测试。
