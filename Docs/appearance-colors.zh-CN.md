# 调整悬浮条、额度和软件界面颜色

从 `0.1.6-preview.4` 起，打开“设置 → 外观与圆环”，可点色块打开选色器，也可输入 `#RRGGBB`。按 Enter、点“应用”或离开输入框后保存；输入过程中不会逐字保存。无效输入会提示并保留原来的设置。

## 悬浮条与吸边收起条

- “悬浮条背景色”：展开后的悬浮条底色，支持四边停靠和自由悬浮。
- “详情卡背景色”：鼠标悬停弹出卡片的底色，与软件卡片背景独立。
- “收起条配色 → 固定颜色”：吸附在桌面边缘时使用“收起条颜色”。
- “收起条配色 → 跟随额度”：按已启用且读数有效的账号中最高已用比例选择颜色。停用账号、错误和陈旧读数不会触发警告；无有效占比时使用“收起条颜色”。耗尽标记按最高风险处理。

颜色修改即时保存并生效，不会重新展开已收起的悬浮条，也不会重设正在进行的展开、收起动画或详情卡指针。

## 按额度占比变色

“颜色变化方式”有三种：

| 方式 | 作用 |
| --- | --- |
| 按阈值分档 | 默认已用低于 75% 用正常色，75% 至 90% 用警告色，90% 起用危险色 |
| 随额度渐变 | 从正常色逐渐过渡到警告色，再过渡到危险色；达到危险阈值后保持危险色 |
| 固定颜色 | 各占比都使用“正常额度颜色” |

正常、警告、危险颜色和两个阈值都可修改，阈值须满足 `0 < 警告 < 危险 ≤ 100`。颜色使用原始“已用”占比判断；切换为显示剩余额度不会反转颜色含义。

圆环、详情额度条和托盘额度使用同一套颜色规则。账号页已经单独设置颜色时，该账号的单独设置优先；想让它跟随全局变色，清空账号页的“自定义颜色”。收起条汇总按全局规则处理。

## 软件界面与恢复默认

软件背景、卡片背景、强调色分别可调。文字会按对应背景选择对比色；悬浮条、详情卡和软件页面分别处理。软件颜色设置不改变导出报告模板和应用文件图标。

从 `0.1.6-preview.7` 起，下拉框收起面板与展开列表也跟随“卡片背景色”，悬停和选中颜色由“软件强调色”生成，文字与箭头按实际控件背景自动选择黑色或白色。无需额外开关。此修复替代 Windows 默认下拉框的浅色绘制，解决深色界面中白底白字的问题；切换主题或配色不会改动当前选项。

提供“原版黑白”“清新绿”“蓝紫”预设。每个颜色旁的“默认”可清除单个覆盖值；“恢复默认配色”清空所有自定义颜色、恢复 75%/90% 阈值，保留当前基础主题。颜色留空时随基础主题使用默认值。

旧版本设置可直接读取。新版本不修改原有账号、代理、自动发送 hi 或开机启动选项。

## 验证边界

验证采用模拟额度与本机控件属性，包括颜色校验、阈值、渐变、保存重载、即时更新、停用账号过滤、耗尽、不同背景的对比色，以及保持收起和指针状态；不发送真实 hi。当前执行会话的 WPF 像素渲染不可用，因此本版不宣称通过新的像素截图验收。

下拉框修复验证了真实模板内的背景、文字和箭头，以及展开选中、高亮、禁用、实时切换配色、方向键和 Escape 操作。295 项核心检查和完整原生功能回归通过（显式跳过像素截图）；六种语言保持各 523 个资源键，不新增配置项。
